# Documentación recuperada de la rama `angelo`

Esta carpeta se copió de `origin/angelo` (commit `6dd5691`) para conservar sus guías y capturas en la rama `steve`. Los archivos originales no se modificaron.

## Qué contiene

- `INICIO.md`: instrucciones para ejecutar el prototipo independiente de Angelo.
- `PROTOTIPO.md`: alcance y flujo de compra propuestos en ese prototipo.
- `SOLID.md`: ejemplos de código de esa rama para la exposición.
- `VALIDACION.md`: pruebas realizadas sobre ese prototipo hasta el 19 de octubre de 2026.
- `capturas/`: imágenes de sus pantallas y de la marca.

## Antes de usar estas guías

Los datos de ejecución y los resultados de pruebas corresponden a la rama de Angelo. **No describen automáticamente la aplicación actual de `steve`**. Por ejemplo, `INICIO.md` indica `https://localhost:7262`, una base local en el puerto 3307 y secretos de usuario propios del prototipo. El perfil HTTPS de `steve` usa `https://localhost:59907` y el proyecto web tiene otro identificador de secretos.

Para una presentación de `steve`, verifica en el código actual cada ejemplo de `SOLID.md` y ejecuta de nuevo las pruebas antes de citar las cifras de `VALIDACION.md`. Las capturas muestran el aspecto del prototipo en la fecha en que se tomaron.
